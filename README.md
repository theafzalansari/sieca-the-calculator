# 🧮 Sieca : The Calculator

A modern and interactive scientific calculator built using **HTML5, CSS3, and JavaScript**.
This project supports advanced mathematical operations along with a clean UI and history tracking.

## 📌 Features

* ✅ Basic arithmetic operations (+, −, ×, ÷)
* ✅ Power functions (^2, ^3)
* ✅ Square root & cube root
* ✅ Trigonometric functions (sin, cos, tan)
* ✅ Degree ↔ Radian mode toggle
* ✅ Factorial calculations (!)
* ✅ Keyboard input support
* ✅ Calculation history with delete option
* ✅ Clean and responsive UI
